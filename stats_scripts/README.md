# Statistical Analysis & Data Visualization 

To complement the raw data processing, this repository inclyes a dedicated set of R scripts designed for downstream statistical analyses and figure production. Once the abundance matrices are generated by the Bash pipeline, these R scripts allowed us to explored, analzyed and visualized the temporal dynamics if the plant and bacterial communities acroos the studied chronological periods.
  

## Packages

Statistical analyses and visualisations were performed under Rstudio using the `ggplot2`, `ggrepel`, `rioja` and `riojaPlot` (available at [https://github.com/nsj3/riojaPlot](https://github.com/nsj3/riojaPlot)) packages for graphical representations, `tidyr`/`dplyr` for data manipulation and vegan for diversity calculation. The visualisations produced include chronological abundance evolution plots, normalised heatmaps and relative composition diagrams by period.
